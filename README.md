# SauceDemo Playwright Automation Framework

## Overview

This project is an end-to-end UI automation framework built using **Playwright** and **JavaScript** to automate test scenarios for the **SauceDemo** web application.

The framework follows industry best practices such as the **Page Object Model (POM)** to ensure maintainability, readability, and scalability. It includes reusable page classes, centralized test data, utility functions, and detailed HTML reports for efficient test execution and debugging.

**Application Under Test:** https://www.saucedemo.com/

---

## Features

* End-to-End UI Automation using Playwright
* Page Object Model (POM) Architecture
* JavaScript Implementation
* Reusable page objects and utilities
* Easy test maintenance and scalability
* Configurable test execution
* Clean project structure following automation best practices
